# hev Checker

**hev Checker** adalah bot Discord utilitas keamanan siber untuk memeriksa reputasi alamat IP dan URL secara instan menggunakan integrasi API dari **VirusTotal** dan **AbuseIPDB**. Jika ditemukan indikasi berbahaya, bot akan mengirimkan peringatan otomatis ke saluran tim keamanan.

## Fitur
* Pengecekan URL dan IP secara bersamaan.
* Integrasi VirusTotal v3 API.
* Integrasi AbuseIPDB API khusus untuk alamat IP.
* Sistem peringatan otomatis (*auto-alert*) berbasis channel Discord tim.
